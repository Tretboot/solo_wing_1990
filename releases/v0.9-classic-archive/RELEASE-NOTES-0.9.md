# SOLO WING 1990 — Release 0.9

**Der letzte Classic-Stand vor dem Sprite-Revamp.**

Diese Version bewahrt das klassische, browserbasierte 2D-Spiel vor der Überarbeitung der Sprites. Schiffe, Cockpit und Effekte werden in dieser Fassung prozedural auf dem Canvas gezeichnet. Der Quellstand ist als eigenständiges, unverändertes Archiv gedacht.

## Spielen

1. `solo_wing_1990_v0.9_classic.zip` herunterladen und entpacken.
2. `index.html` im Browser öffnen – oder den entpackten Ordner unverändert auf einen statischen Webserver hosten.

Es werden keine externen Bibliotheken, Downloads oder Build-Schritte benötigt. `index.html` ist der Einstiegspunkt; `data/` und `js/` müssen neben der Datei erhalten bleiben. Spielstände werden browserseitig gespeichert.

## Inhalt

- Retro-Space-Shooter mit Canvas-Rendering und prozeduraler Pixelgrafik.
- Trägerleben mit Räumen, Crew, NPC-Dialogen und Briefings.
- Flug- und Missionsablauf mit Start, Weltraumkampf, Landung und Debriefing.
- Cockpit mit Radar, Navigation und Missionsfunktionen.
- Web-Audio-Soundeffekte und optionale Sprachausgabe, abhängig von den Browserfunktionen.
- Spielstände im Browser.

## Steuerung

| Eingabe | Funktion |
|---|---|
| W/A/S/D oder Pfeiltasten | Bewegen |
| Umschalt (Shift) | Nachbrenner / höherer Vorschub |
| Q / E | Rollen |
| Maus | Zielen |
| Leertaste oder Mausklick | Feuern |
| T | Autopilot |
| N | Navigationskarte |
| M | Sprachausgabe ein/aus |
| O | Sound ein/aus |
| Esc | Menü |
| Mausklick im Träger | Türen, NPCs und interaktive Stationen |

## Paket

Das ZIP enthält ausschließlich die zum Spielen benötigten Dateien und die Lizenz. Screenshots, Entwicklungsnotizen und historische Release-Kopien sind nicht enthalten.
