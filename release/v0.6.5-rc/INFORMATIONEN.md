# SOLO WING 1990 — v0.6.5-rc (Release Candidate)

## STARTEN
`index.html` im Browser öffnen. Das ist alles. Kein Server. Kein Internet. Kein Tracking. Nur Fax.

## STEUERUNG
| Eingabe | Funktion |
|---------|----------|
| W/S/D oder Pfeile | Bewegen (Drift) |
| Q / E | Rollen |
| Maus | Zielen |
| Leertaste / Klick | Feuer |
| T | Autopilot |
| N | Nav-Karte |
| M | TTS ein/aus |
| O | Sound ein/aus |
| I (im Menü) | Info-Panel |
| ESC | Menü |
| Klick (im Träger) | Türen / NPCs / START / Wandkarte |

Multi-Input: Jedes aktive Gerät = +1 Laser-Slot (max 3). Das ist kein Bug. Das ist Physik.

## INHALT DIESES CANDIDATES
- 3 Missionen, 11 Räume, 18 Crew-Mitglieder + 5 Piloten
- Intro (Asteroidenfeld) → Pilotenname → Akademie → **Transfer-Zwischenszene** → Träger
- Landung → **Hangar** (Bolt kommentiert je nach Schaden) → **Debriefing** → Träger
- 7 neue NPCs (Archiv, Löffel, Stille, Mutters, Spiegel, Rohr, Nadel)
- Klickbare Wandkarte (Fullscreen-Karte mit Schiff-Umriss), Cheatmenü [1]/[2] im Menü
- Rollen (Q/E), Nav-Karte (N), TTS mit 14 Stimmenprofilen

## BEKANNT LIMITIERT
- Cheatmenü ist im Release entfernt (Flag `SW.Config.cheatEnabled` in `js/config.js` auf `false`).
- Fax-Drucker UI, Aktenschrank, Optimierer-Erscheinen, 3 Enden: offen (TODO.md).
